Radio 24px & Sombra Suave

Esquinas con radio exacto de 24px, sin bordes duros de separación (`border-0`), empleando elevación sutil `shadow(y=4, blur=16, 6%)`.

Cifras Tabulares (Tabular figures)

Los números "24", "12" y "0" están formateados con `font-variant-numeric: tabular-nums` y peso Medium para comparación inmediata.

Acentos Terracota & Miel

Micro-iconos discretos: terracota para recetas generadas y miel para favoritas. Sin competir jamás con la acción primaria (`FAB`).

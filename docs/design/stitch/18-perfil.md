Sazón — Profile (tab "Perfil").

Screen content:
- Header: a large round avatar (initials on the chosen colour) with the display name beside it, the
  caption "Tu perfil" and an "Editar" link.
- Section "Resumen": two compact stat cards side by side — "24 recetas generadas" and "12 favoritas".
- Section "Sugerencias": a row reading "Última actualización: hace 3 días" with a secondary pill button
  "Actualizar sugerencias" and the helper "Se renuevan cuando cambian tus preferencias."
- Section "Mis preferencias": rows mirroring the onboarding choices — Alimentación, Estilo, Cocinas
  favoritas, Ingredientes que me gustan, Ingredientes que me evito — each showing the current values as
  chips and a chevron. Each row opens the SAME editor used in the corresponding onboarding step,
  presented as a bottom sheet over the profile. Do not design separate duplicated editor screens.
- Section "Alergias e intolerancias": honey-tinted card listing the selected restrictions, with the
  caption "Esto se usa para evitar ingredientes peligrosos" and an "Editar" link.
- Section "Mi cocina": Nivel de cocina, Tiempo disponible and Comensales habituales.
- Section "Ajustes": rows for Notificaciones, Idioma, Sobre la app — render them as disabled or
  coming-soon, they are not part of this design.
- A destructive text button "Borrar mis datos".

Also include the persistent bottom navigation bar (Perfil active). Light and dark. Only this screen.
